Journal des erreurs

Erreurs de code survenues dans l'appli des chauffeurs, regroupées par message (300 dernières). Les coupures de réseau ne sont pas comptées.

Annonce dans l'appli

Le bandeau s'affiche en haut de l'appli à la prochaine ouverture. Chaque chauffeur peut le fermer ; modifier le texte le fait réapparaître.

Sauvegarde

Un fichier JSON avec les comptes, toutes les saisies, les offres et les signalements. À faire chaque semaine et à ranger hors de Supabase (ordinateur, Drive).

Sites vitrines
