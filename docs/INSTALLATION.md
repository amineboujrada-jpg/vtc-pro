# Installer VTC Rentable sur son téléphone

## iPhone

1. Ouvrir **Safari** et aller sur https://app.vtcrentable.com/
2. Toucher le bouton **Partager** (le carré avec une flèche vers le haut).
3. Choisir **Sur l'écran d'accueil**, puis **Ajouter**.

L'icône VTC Rentable apparaît sur l'écran d'accueil. L'appli s'ouvre en plein écran, marche sans réseau et se met à
jour toute seule. Il n'y a pas de fichier à télécharger ni de passage par l'App Store.

## Android

**Avec le fichier d'installation (APK)**

1. Télécharger `vtc-rentable.apk` :
   https://github.com/amineboujrada-jpg/vtc-pro/releases/download/android-latest/vtc-rentable.apk
2. Ouvrir le fichier téléchargé. Si le téléphone le demande, autoriser l'installation depuis cette source.
3. Toucher **Installer**.

**Sans fichier** : ouvrir https://app.vtcrentable.com/ dans Chrome, menu ⋮, **Installer l'application**.

Dans les deux cas, les données sont les mêmes : il suffit de se connecter avec son compte.
